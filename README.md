# تسميع الشاطبية

تطبيق ويب لتسميع منظومة «حرز الأماني ووجه التهاني في القراءات السبع» (الشاطبية) للإمام القاسم بن فيُّره الشاطبي (١١٧٣ بيتًا) بالصوت: تُخفى الأبيات، ويُسمِّع الحافظ، فتتلوّن الكلمات صحيحة أو خاطئة أو ساقطة.

- النص: نسخة الشيخ عبد المحسن بن محمد القاسم («متون طالب العلم – الشاطبية»، المدينة المنورة، ١٤٤٥هـ) كما استُخرجت وروجعت على صور الطبعة في مشروع FarisAlRasheed/shatibyah.
- الكود في `app.src.html` والنص في `shatibiya_data.json`، وبعد أي تعديل: `python3 build.py`.
